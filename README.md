# 🎮 Tic Tac Toe – Glassic Game Series

An advanced and beautifully designed **Tic Tac Toe web game** built using **HTML, CSS, and JavaScript**, featuring dynamic board sizes, sound effects, modals, and a polished UI experience.

----

## ✨ Features

* 🎯 Multiple board sizes: **3×3, 4×4, 5×5**
* 🎨 Elegant UI with animated bubble background
* 👥 Two-player turn-based gameplay
* 🔄 Real-time turn indicator
* 🧠 Smart win detection (rows, columns, diagonals)
* 📊 Game summary with move count
* 📘 Rules modal
* ⚙️ Settings panel:

  * Tap sound toggle
  * Win sound toggle
  * Background music control
* 🔊 Sound effects & background music support
* 🚪 Withdraw and restart options

## 🎮 How to Play

* Select board size from the start screen
* Players take turns placing **X** and **O**
* First player to align symbols wins:

  * 3×3 → 3 in a row
  * 4×4 → 4 in a row
  * 5×5 → 5 in a row
* If all cells fill → **Draw**
